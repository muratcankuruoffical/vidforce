# VidForce Setup Guide

## ⚠️ Important: Flutter SDK Required

This project requires Flutter SDK to be installed on your machine. Since Flutter was not available during initial setup, some generated files are missing.

## Option 1: Complete Setup (Recommended)

If you have Flutter installed on another machine or want to install it:

### 1. Install Flutter SDK

```bash
# macOS/Linux
git clone https://github.com/flutter/flutter.git -b stable
export PATH="$PATH:`pwd`/flutter/bin"

# Windows
# Download from: https://docs.flutter.dev/get-started/install
```

### 2. Verify Installation

```bash
flutter doctor
```

### 3. Initialize Flutter Project Files

Run this command in the project directory to generate missing platform files:

```bash
# This will regenerate platform-specific files while keeping your lib/ folder
flutter create . --org com.vidforce --platforms=android,ios,web
```

**Note:** This will NOT overwrite your existing code in `lib/` folder.

### 4. Get Dependencies

```bash
flutter pub get
```

### 5. Run the App

```bash
# For web
flutter run -d chrome

# For Android
flutter run -d android

# For iOS (macOS only)
flutter run -d ios
```

## Option 2: Use Docker (Alternative)

If you don't want to install Flutter locally, you can use Docker:

```bash
# Build Flutter in Docker
docker run --rm -v $(pwd):/app -w /app cirrusci/flutter:stable flutter pub get

# Run on web
docker run --rm -v $(pwd):/app -w /app -p 8080:8080 cirrusci/flutter:stable flutter run -d web-server --web-port=8080
```

## Option 3: GitHub Codespaces / GitPod

You can also use cloud development environments:

### GitHub Codespaces

1. Open repository in GitHub
2. Click "Code" → "Codespaces" → "Create codespace"
3. Install Flutter extension
4. Run `flutter pub get`
5. Run `flutter run -d web-server`

### GitPod

Add `.gitpod.yml`:

```yaml
tasks:
  - init: |
      git clone https://github.com/flutter/flutter.git -b stable
      export PATH="$PATH:`pwd`/flutter/bin"
      flutter pub get
    command: flutter run -d web-server

ports:
  - port: 8080
    onOpen: open-preview
```

## Troubleshooting

### Error: "flutter: command not found"

Install Flutter SDK using the instructions above.

### Error: "Unable to find bundled Java version"

Update Android Studio or install JDK 11+:

```bash
# macOS
brew install openjdk@11

# Ubuntu/Debian
sudo apt install openjdk-11-jdk
```

### Error: "CocoaPods not installed" (iOS only)

```bash
# macOS
sudo gem install cocoapods
cd ios
pod install
```

### Error: "Gradle build failed"

```bash
cd android
./gradlew clean
cd ..
flutter clean
flutter pub get
```
